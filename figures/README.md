## Conventions

- Titles state the finding, not the chart type: *"Late delivery is associated with poor
  reviews"*, not *"Review score by lateness band"*.
- Sample size is shown wherever group sizes differ materially.
- Every figure states its unit of analysis where it is not obvious.
- Language follows `docs/methodology.md` — associative, not causal.
